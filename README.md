# Held, Quietly

A tiny Python program that writes one short text — a kettle boiled, a
window steamed soft, a kitchen that is briefly a small warm country with
no news in it — to `/output/entry.txt`. The scene asks nothing of the
reader and gives no instructions; it simply sits still, warmly, for a
little while, and lets the reader sit with it.
